# Booking-Cancellation-Dashboard

## 📊 Project Overview

The **Booking-Cancellation-Dashboard** is a data analysis project focused on understanding hotel booking trends and cancellation patterns. The project involves cleaning and transforming raw booking data, performing exploratory data analysis, and presenting key insights through an interactive dashboard built in Microsoft Excel using pivot tables.

---

## 🎯 Objectives

* Analyze hotel booking data to identify trends and patterns
* Understand the factors contributing to booking cancellations
* Perform data cleaning and preprocessing for accurate analysis
* Create an interactive and user-friendly dashboard for insights

---

## 🗂️ Dataset Description

The dataset used in this project contains information related to hotel bookings, including:

* Booking dates
* Customer details
* Room types
* Length of stay
* Booking status (confirmed/cancelled)
* Payment and reservation details

---

## 🧹 Data Cleaning & Preparation

The following steps were performed to prepare the dataset:

* Removed duplicates and handled missing values
* Standardized data formats (dates, categories, etc.)
* Filtered irrelevant or inconsistent records
* Created calculated columns for better analysis
* Grouped and categorized data where necessary

---

## 📈 Data Analysis

Key analysis performed includes:

* Cancellation rate analysis
* Booking trends over time
* Customer segmentation
* Seasonal patterns in bookings
* Impact of booking channels and customer types on cancellations

---

## 📊 Dashboard Features

The dashboard was created using **Microsoft Excel** with pivot tables and includes:

* Interactive filters and slicers
* Summary metrics (total bookings, cancellations, cancellation rate)
* Visualizations such as charts and graphs
* Trend analysis over time
* Category-wise breakdowns (e.g., hotel type, customer type)

---

## 🛠️ Tools & Technologies

* Basic Data Analysis Methods
